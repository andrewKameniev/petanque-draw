# План семінару: Модуль жеребкування Petanque Draw

## Вступ (5 хв)

Привіт усім! Мене звати [Ім'я], я розробник модуля жеребкування Petanque Draw.

Сьогодні ми детально розберемо цей інструмент — від створення турніру до готового протоколу. Це єдина система, яка покриває весь цикл проведення турніру з петанку: імпорт учасників з порталу, жеребкування за різними системами, публічний доступ для глядачів, телевізійна трансляція на великий екран, і в кінці — офіційний протокол.

Ось що ми сьогодні пройдемо:

1. Створення турніру та імпорт команд з порталу
2. Всі системи жеребкування — коли яку обирати, які комбінації можливі
3. Налаштування — до старту і під час турніру
4. Публічне посилання, кастомні URL, QR-коди
5. Телевізійна вьюха для екранів на майданчику
6. Архів та протоколи

По ходу семінару я буду все показувати наживо — створювати турніри, запускати жеребкування, демонструвати публічну сторінку, ТВ-режим, і так далі. Тобто ви побачите кожну функцію в дії, а не тільки слайди.

## Частина 1: Створення турніру та імпорт з порталу (10 хв)

### 1.1 Створення нового турніру

- Натиснути "Створити турнір"
- Обмеження: максимум 20 активних турнірів на акаунт

### 1.2 Імпорт команд з порталу

- Зайти на portal.petanque.org.ua → знайти турнір → скопіювати ID з URL
- В додатку: вставити ID порталу → натиснути "Імпорт"
- Що імпортується: назва команди, рейтинг, гравці (ПІБ, клуб, спортивне звання, аватар), ID команди на порталі
- **Важливо:** дублікати імен автоматично відхиляються
- Після імпорту зберігається зв'язок з порталом (для протоколу, оновлення даних)

### 1.3 Ручне додавання команд

- Можна комбінувати: частину імпортувати, частину додати вручну
- Поля: назва команди, рейтинг (опціонально)

## Частина 2: Системи жеребкування (25 хв)

### 2.1 Швейцарська система (Swiss)

**Коли використовувати:** основна система для більшості турнірів, від 5 команд і більше

**Як працює:**

- 1-й тур: випадкові пари (або за рейтингом, якщо ввімкнено "Використовувати рейтинг")
- Наступні тури: пари формуються за принципом "перший з останнім" всередині однакової кількості перемог
- Система автоматично уникає повторних зустрічей
- При непарній кількості — технічна перемога для найнижчої команди (не повторюється)

**Ранжування:** перемоги → бухгольц → малий бухгольц → різниця очок → набрані очки → рейтинг

**Рекомендована кількість турів:** log₂(кількість команд). Наприклад:

- 16 команд → 4 тури
- 32 команди → 5 турів
- 60 команд → 6 турів

**Менше турів ніж рекомендовано:**

- Технічно працює без проблем — просто менш точне ранжування
- Лідери можуть не зустрітися між собою і мати однаковий рахунок перемог
- Ранжування більше залежить від бухгольца та різниці очок, а не від прямих зустрічей
- Підходить коли обмежений час або є плей-оф (де і так зустрінуться)

**Більше турів ніж рекомендовано — ОБЕРЕЖНО:**

- Чим більше турів, тим складніше алгоритму знайти унікальні пари без повторів
- Максимум теоретично можливих турів = кількість команд − 1 (кожен зіграє з кожним)
- Але швейцарка парує в межах однакової кількості перемог, тому реальна межа НИЖЧА
- При малій кількості команд і багатьох турах система може видати помилку "Неможливо жеребкувати" — це значить що для когось не залишилось нового суперника в його брекеті
- Приклад ризику: 8 команд і 6+ турів — майже напевно заблокується

**Чи може повторитися суперник?**

- НІ — система НІКОЛИ не ставить повторну зустріч. Кожна команда зберігає список всіх минулих суперників, і алгоритм перевіряє кожну потенційну пару
- Якщо алгоритм не може знайти жодної валідної пари (всі можливі суперники вже зіграні) — він повертає помилку, а не допускає повтор
- Алгоритм спочатку пробує стандартне паруватися, потім "розмотує" назад (backtracking) і перебудовує пари. Якщо навіть після повного перебору не вдалося — зупиняється

**Переваги:** всі грають усі тури, швидко виявляє лідерів, гнучка кількість турів
**Недоліки:** не гарантує що кращі зустрінуться між собою

**Комбінації:**

| Комбінація                 | Опис                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| Swiss + Playoff            | Кваліфікаційні тури → топ-N у плей-оф                                |
| Swiss + Cadrage + Playoff  | "Бульбашкові" команди грають кадраж (стикові), переможці в плей-оф   |
| Swiss + Barrage + Playoff  | Середні команди формують барражні групи по 4, кваліфіканти в плей-оф |
| Swiss + Cadrage + Турнір Б | Ті хто програв кадраж йдуть у паралельний Турнір Б                   |

**Важливо про Barrage:**

- Доступний ТІЛЬКИ для швейцарської системи (не для груп!)
- Формує групи по 4 команди з середньої частини таблиці
- Кожна група грає кругову (3 гри) — переможці виходять у плей-оф
- Кількість команд у бараж: 8, 12, 16, 20...

### 2.2 Групи (Groups / Round-Robin)

**Коли використовувати:** коли потрібна кругова всередині груп, або коли хочете розбити великий турнір на менші

**Як працює:**

- Обираєте кількість команд у групі (або всі в одній групі = повна кругова)
- Два формати всередині групи:
  - **Кругова (Round-Robin):** кожен грає з кожним. Алгоритм ротації з закріпленою 1-ю позицією
  - **Швейцарка в групі:** швейцарська система всередині кожної групи (вказуєте кількість турів)

**Методи розподілу по групах:**

- **Seeded (за горщиками):** класичний посів — найсильніші розкидані по різних групах
- **Snake (змійка):** 1-й у групу A, 2-й у B, 3-й у C, потім назад C, B, A...
- **Balanced random:** 1000 випадкових розподілів, обирається найрівніший за сумою рейтингів

**Кількість кіл (для повної кругової):** можна задати 1, 2 або більше повних кіл зустрічей

**Переваги:** справедлива — кожен грає з кожним у групі, легко зрозуміти
**Недоліки:** багато ігор при великій групі, довго при великій кількості команд

**Комбінація:** Groups + Playoff — найкращі з кожної групи виходять у плей-оф

---

### 2.3 Плей-оф (Playoff)

**Коли використовувати:** як фінальна стадія або як самостійна система (прямий нокаут)

**Два формати на вибір:**

#### Одинарне вибування (Single Elimination)

- Класичний нокаут: програв — вибув
- Сітка: 4, 8, 16, 32, 64 команди (ступені двійки)
- Посів: 1 vs 8, 4 vs 5, 2 vs 7, 3 vs 6 (для 8 команд) — лідери зустрічаються якомога пізніше
- Включає матч за 3-є місце
- При непарній кількості — технічні перемоги (byes) для вищих за рейтингом

**Переваги:** швидко, драматично, зрозуміло для глядачів
**Недоліки:** один програш = вибування, мало ігор для більшості

#### Подвійне вибування (Double Elimination)

- Програв першу гру — падаєш у нижню сітку (losers bracket)
- Програв у нижній сітці — вибуваєш остаточно
- Тобто кожен має право на одну поразку

**Як працює:**

- Всі починають у верхній сітці (winners bracket)
- Програвші першого раунду верхньої сітки потрапляють у нижню
- Кожен наступний раунд верхньої сітки "скидає" програвших у нижню
- Скидання перехрестне (crossed) — щоб уникнути негайного реваншу після падіння
- Переможець верхньої сітки грає з переможцем нижньої у Гранд-Фіналі
- Один вирішальний Гранд-Фінал (без "переваги" upper bracket)

**Розміри:** будь-яка кількість учасників від 2-х, автоматично доповнюється byes до ступеня двійки

**Що бачить глядач:** горизонтально скролюваний канвас з обома сітками (верхня + нижня)

**Ранжування:**

1. Переможець Гранд-Фіналу
2. Програвший Гранд-Фіналу
3. далі — по місцю вибування з нижньої сітки (пізніше вибув = вище)

**Переваги:** справедливіше — один поганий день не закінчує турнір; більше ігор для кожного
**Недоліки:** довше за single elimination; складніша сітка для розуміння глядачами

**Як самостійна система:** можна запустити турнір одразу в форматі плей-оф (прямий нокаут без кваліфікації) — обираючи формат одинарного чи подвійного вибування

---

### 2.4 Пули (Poules)

**Коли використовувати:** коли потрібна специфічна система з групами по 4 + автоматичним відбором

**Обмеження:** кількість команд повинна ділитися на 4, мінімум 8 команд

**Як працює (фіксовано 3 тури):**

- Тур 1: A×C, B×D (перехресно)
- Тур 2: переможці між собою, програвші між собою
- Тур 3: бараж — дві команди з рівно 1 перемогою грають між собою

**Кваліфікація:** команди з 2+ перемогами автоматично виходять у плей-оф

**Розподіл:** змійка за рейтингом

**Переваги:** компактна (лише 3 гри), кожен має шанс на кваліфікацію
**Недоліки:** жорсткий формат, тільки кратне 4-м

---

### 2.5 Суперміле (Supermele)

**Коли використовувати:** дружні/соціальні турніри, знайомство, тренування

**Як працює:**

- Кожен тур формуються НОВІ команди з гравців (не фіксовані команди!)
- Рахується індивідуальний рейтинг кожного гравця

**Режими:**

- **Ideal (збалансований):** найсильніший гравець у парі з найслабшим
- **Standard (випадковий):** повністю випадкові пари

**Налаштування:**

- Гравців у команді: 2 (дублет) або 3 (триплет)
- Тет-а-тет: при непарній кількості — замість технічної створюється гра 1×1 (дублет ділиться)

**Переваги:** соціальний формат, всі грають з усіма, відслідковується що ви вже грали разом
**Недоліки:** не для серйозних змагань

---

### 2.6 Тір де Пресізьон (Tir de Précision)

**Коли використовувати:** індивідуальні змагання з точності кидків

**Як працює:**

- Індивідуальна дисципліна (не команди)
- 5 ательє на тур, дистанції: 6, 7, 8, 9 м (повна) або 6, 7, 8 м (юніори)
- Бали: каро=5, реюсі=3, туше=1, манке=0
- Дворундова система (опціонально): топ-4 одразу в плей-оф, наступні 16 у 2-й раунд
- Плей-оф: 1×1 поєдинки з посівом

**Налаштування:**

- Дворундова система: вкл/викл
- Юніорський турнір: скорочені дистанції

**Переваги:** єдина індивідуальна дисципліна, автоматичний експорт на портал
**Недоліки:** специфічний формат, тільки для тір

## Частина 3: Налаштування перед стартом (10 хв)

### 3.1 Основні налаштування

- **Використовувати рейтинг:** впливає на посів у 1-му турі (швейцарка), розподіл по групах, та посів у плей-оф
- **Кількість турів (швейцарка):** додаток підказує оптимальну (log₂ команд)
- **Плей-оф:** кількість команд (4, 8, 16, 32), кадраж, бараж
- **Турнір Б:** паралельний турнір для вибулих

### 3.2 Тайм-ліміт

- Час на гру (швейцарка/групи): 30-90 хвилин
- Час на плей-оф: окремо або без обмеження
- Без тайм-ліміту у фіналі: опція
- Кількість кошонетів: 1 або 2 (впливає на технічний рахунок при тайм-ауті)

### 3.3 Додаткові налаштування (розгортаються)

- **Призові місця:** скільки виділяти (для швейцарки без плей-оф)
- **Порахунковий рахунок:** фіксація рахунку по кошонетах (для кожної стадії окремо)
- **Технічний рахунок:** переможець/програвший (за замовч. 13:7)
- **Макс. рахунок:** за замовч. 13
- **Доріжки (поля):**
  - Пул (діапазон від-до) або послідовно (з якого номера)
  - Виключені доріжки (через кому)
  - Алгоритм уникає повторних доріжок для команд
- **Тестовий турнір:** позначка для тренувальних

### 3.4 Що можна змінити ПІСЛЯ старту

- Плей-оф (вкл/викл, кількість команд) — до запуску плей-оф
- Тайм-ліміт та кошонети — будь-коли
- Кількість турів — будь-коли
- Призові місця — будь-коли
- Доріжки — будь-коли

### 3.5 Що НЕ МОЖНА змінити після старту

- Максимальний рахунок
- Технічний рахунок
- Систему жеребкування

## Частина 4: Під час турніру — адмін-панель (10 хв)

### 4.1 Вкладки адмін-панелі

| Вкладка        | Що містить                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| **Команди**    | Список команд з гравцями, клубами, рейтингом. Натискання на команду → розгортається панель історії ігор |
| **Ігри**       | Поточний тур — список пар з полями для введення рахунку, номери доріжок                                 |
| **Результати** | Таблиця результатів по кожному туру (хто з ким грав, рахунок)                                           |
| **Ранжування** | Турнірна таблиця: місце, команда, перемоги, бухгольц, різниця очок                                      |
| **Стріми**     | Прив'язка посилань на трансляції (YouTube/Twitch/Facebook/Instagram) до команд або доріжок              |

### 4.2 Жеребкування наступного туру

- Автоматичне формування пар за алгоритмом системи
- Перегляд пар перед підтвердженням
- Якщо алгоритм не може знайти пари — повідомлення про помилку

### 4.3 Введення результатів

- Натискаєте на гру → вводите рахунок обох команд
- Порахунковий рахунок (якщо ввімкнено): чіпси з проміжним рахунком по кошонетах
- Коли всі ігри туру завершені — можна жеребкувати наступний тур

### 4.4 Історія ігор команди (ParticipantGames)

- Натиснути на команду в списку → розгортається панель з усіма іграми
- Показує: загальні W/L, набрані:пропущені очки
- Кожна гра: номер, суперник, рахунок, W/L
- Кнопка переходу до суперника (стрілочка) — відкриває його історію
- Кнопка статистики — переходить в модуль статистики з контекстом цієї гри
- Кнопка гравців — показує склад команди-суперника

### 4.5 Таймер

- Запуск/пауза/рестарт зворотного відліку
- Синхронізується на всіх пристроях та публічній сторінці
- Окремий час для швейцарки та плей-оф

### 4.6 Колаборатори

- Додати суддю/скорера за email
- Ролі: owner (повний доступ), admin (редагування), scorer (тільки рахунок)
- Кілька людей можуть вводити результати одночасно в реальному часі

## Частина 5: Публічне посилання (10 хв)

### 5.1 Стандартне посилання

- Генерується автоматично для кожного турніру
- Формат: `petanque-draw/#/tournament?ref={uid}.{id}`
- Копіювання одним натисканням

### 5.2 Кастомний slug (коротке посилання)

- Розділ "Маршрути" в меню
- Створюєте запам'ятовуване посилання: `petanque-draw/#/public/kyiv-open-2026`
- Правила: латиниця, цифри, дефіс; 3-50 символів
- Можна створити ДО початку турніру (покаже "coming soon")
- Прив'язується до турніру через інтерфейс

### 5.3 Що бачать глядачі на публічній сторінці

**Статус та оформлення:**

- Бейдж статусу: активний / завершений / не розпочатий
- Переможець з анімацією трофею та подіум (золото/срібло/бронза)
- Оновлення в реальному часі (Firebase) — не треба оновлювати сторінку

**Вкладки публічної сторінки:**

| Вкладка          | Що містить                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------- |
| **Поточний тур** | Список ігор що граються зараз (з'являється тільки під час активного туру/плей-оф/кадражу) |
| **Команди**      | Список усіх команд. Натискання → розгортається історія ігор команди                       |
| **Ранжування**   | Турнірна таблиця (не показується для чистого плей-оф)                                     |
| **Результати**   | Результати по турах у форматі карток                                                      |

**Пошук та фільтрація (TeamSearch):**

- Кнопка пошуку на вкладці поточного туру
- Пошук за назвою команди АБО за назвою клубу
- Клуби виділені окремо іконкою будинку
- Після вибору — ця команда/клуб підсвічується у всіх вкладках (ігри, ранжування, результати)
- Чіп-фільтр з хрестиком для скидання

**Історія ігор команди:**

- Натиснути на команду → розгортається панель ParticipantGames
- Всі ігри команди по стадіях (тур 1, тур 2..., кадраж, плей-оф)
- Кожна гра: порядковий номер, суперник, рахунок, W/L
- Кнопка переходу до суперника (навігація між командами)
- Кнопка статистики (перехід у модуль Stats з контекстом гри)
- Кнопка показу складу суперника (гравці)

**Додатково:**

- Таймер зворотного відліку (якщо запущено)
- Стрімові посилання (YouTube, Twitch, Facebook, Instagram) біля ігор
- Перемикач Турнір A / Турнір Б
- Порахунковий рахунок (чіпси з проміжними) якщо ввімкнено кошонети

### 5.4 QR-коди

- Генеруються для публічного посилання та ТВ-посилання
- Розмір 300px, рівень корекції "H" (високий — можна закрити частину)
- Для кастомних маршрутів — окремий QR на сторінці маршрутів
- Зручно друкувати на афішах чи показувати на екрані

## Частина 6: Телевізійна вьюха (TV Dashboard) (7 хв)

### 6.1 Що це

- Окрема сторінка для великих екранів на майданчику
- Фіксований розмір 1920×1080
- Підключається через HDMI до телевізора/проектора

### 6.2 Як відкрити

- QR-код або посилання з модалки QR-кодів
- Формат: `petanque-draw/#/tv?ref={uid}.{id}`

### 6.3 Що показує

- **Ліва частина:** логотип + сітка матчів (автоматично 1-4 колонки)
- **Права панель:** турнірна таблиця з авто-пагінацією (27 команд на сторінку, перегортає кожні 12 сек)
- **Футер:** бігуча стрічка зі спонсорами
- **Верх:** годинник, зворотний відлік, індикатор кошонетів, фаза (Тур N / Кадраж / Плей-оф / Бараж)
- **Плей-оф:** SVG-сітка з конекторами, матч за 3-є, подіум
- **Реєстрація:** коли є команди але турнір не почався — показує список учасників

### 6.4 Кольорові схеми

- За замовчуванням (бірюзова)
- `tv--default` (фіолетова)
- `tv--autumn` (золота)
- Додатковий параметр `?header=woman` — жіночий хедер

### 6.5 Обмеження

- Для тір-турнірів ТВ-вьюха прихована (не підтримується)

## Частина 7: Архів (5 хв)

### 7.1 Збереження в архів

- Кнопка з'являється тільки коли турнір ЗАВЕРШЕНИЙ (зіграний останній тур або фінал плей-оф)
- Вводите назву для архівного запису
- Після збереження турнір переноситься в архів

### 7.2 Що є в архіві

- Список збережених турнірів з назвою, датою, тегом формату (Тет/Дублет/Триплет)
- Вкладки: команди, результати, ранжування, протокол
- Протокол доступний тільки для ЗАВЕРШЕНИХ турнірів

### 7.3 Дії з архівними турнірами

- Перейменувати
- Видалити
- Встановити/оновити ID порталу
- Оновити логотипи клубів з порталу
- Скопіювати публічне посилання
- Розархівувати (повернути в активні)

## Частина 8: Протоколи (7 хв)

### 8.1 Доступ

- Доступний для завершених турнірів (в активних і архівних)
- Захищений паролем (платна функція, 300 грн)

### 8.2 Що містить протокол (офіційний формат України)

1. **Титульна сторінка:** назва турніру, дати, місце проведення, організатор, головний суддя, загальна кількість учасників
2. **Таблиця учасників:** №, ПІБ, область (за club_id), тренер, спортивне звання, місце кваліфікації, підсумкове місце
3. **Результати:** кваліфікаційні тури, таблиця рангу
4. **Плей-оф результати** (якщо був)
5. **Таблиця суддів:** ПІБ, посада, категорія, номер сертифіката, область
6. **Блок підписів:** головний суддя, суддя, головний секретар, президент федерації

### 8.3 Можливості редагування

- Місце проведення, організатор, тренери — редагується прямо в тексті
- Додавання рядків суддів
- Вмикання/вимикання колонки сертифікатів
- Оновлення даних гравців з порталу (по-батькові, регіони)

### 8.4 Експорт

- PDF-експорт (html2pdf)
- DOCX-експорт (Word-документ для подальшого редагування)
- Копіювання у буфер обміну (текст)
- Збереження стану в localStorage (не втрачається при перезавантаженні)

### 8.5 Тір-протокол

- Окремий формат для тір-турнірів (специфічна таблиця з ательє)

## Додаток: Швидка довідка по комбінаціях систем

```
Swiss ─────────────────────────────────> Фінал (за турнірною таблицею)
Swiss ──────────────────── Playoff ────> Фінал
Swiss ─────── Cadrage ──── Playoff ────> Фінал
Swiss ─────── Barrage ──── Playoff ────> Фінал (тільки Swiss!)
Swiss ─────── Cadrage ──── Турнір Б ──> (для програвших кадраж)
Groups ─────────────────── Playoff ────> Фінал
Poules ─────────────────── Playoff ────> Фінал
Playoff (single) ──────────────────────> Фінал
Playoff (double) ── Upper + Lower ─────> Гранд-Фінал
Supermele ─────────────────────────────> (без плей-оф, за перемогами)
Tir ───────────────────── Tir Playoff ─> Фінал
```

**Бараж:** ТІЛЬКИ Swiss. НЕ доступний для Groups/Poules/Playoff.
**Кадраж:** Swiss або Groups. НЕ доступний для Poules/Playoff/Supermele/Tir.
**Турнір Б:** Swiss або Groups. Потрібен кадраж з опцією "програвші в Турнір Б".
