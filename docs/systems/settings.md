# Tournament Settings

Configuration options available in the Preferences modal.

## General Settings
| Setting | Default | Purpose |
|---------|---------|---------|
| System | Swiss | Tournament format (swiss, groups, poules, supermele, tir) |
| Technical score | 13:7 | Walkover result for bye rounds |
| Max score | 13 | Game ends at this score (validation) |
| Fields start | 1 | First lane number |
| Use rating | false | Seeded first-round pairing based on player ratings |
| Time limit | disabled | Per-round time limit (shown to public viewers) |
| Cochonettes | disabled | Additional cochonettes count after time expires |

## Swiss-Specific
| Setting | Default | Purpose |
|---------|---------|---------|
| Rounds count | — | Target number of Swiss rounds |
| Playoff teams | 8 | How many advance to knockout |
| With cadrage | false | Add play-in round before playoff |
| Tournament B | false | Create parallel tournament for non-playoff teams |
| Playoff enabled | false | Show playoff option in ranking tab |

## Groups-Specific
| Setting | Default | Purpose |
|---------|---------|---------|
| Teams in group | 4 | Group size for round-robin |

## Supermele-Specific
| Setting | Default | Purpose |
|---------|---------|---------|
| Players in team | 2 | Doubles (2) or triples (3) |

## TIR-Specific
| Setting | Default | Purpose |
|---------|---------|---------|
| Junior | false | Use 3 distances (6-8m) instead of 4 (6-9m) |

## Public View Settings
| Setting | Purpose |
|---------|---------|
| Tournament message | Free text shown to public viewers |
| Share link | Auto-generated URL for spectators |
