# Task scope

Read [README.md](./README.md). Use [TEMPLATE.md](./TEMPLATE.md) only when work
needs a persistent multi-step handoff; ordinary tasks do not need a task file.

- Make the task self-contained: goal, non-goals, owners, compatibility constraints, focused tests, docs impact, and acceptance criteria.
- Record characterization coverage before risky refactoring.
- Separate behavior changes from behavior-preserving extraction.
- Name file ownership and concurrent overlap so agents do not edit the same area blindly.
- Keep temporary execution evidence here and move enduring decisions into `docs/`.
- Update the nearest task index while active.
- Do not restore completed `tasks/code-quality-audit/` briefs.
- Report exact validation commands and outcomes without copying changing totals into durable docs.
